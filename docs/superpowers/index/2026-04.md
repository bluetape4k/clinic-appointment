# Superpowers 발전 기록 — 2026-04

## 2026-04-21: H2 + PostgreSQL + MySQL8 multi-DB 테스트 지원

**무엇을 했나**: appointment-core/api 모듈에 H2(기본) / PostgreSQL / MySQL8 Testcontainer 멀티 DB 테스트 지원을 추가했습니다. appointment-api에는 Spring Profile 기반 DataSource 동적 주입과 CI matrix 병렬 실행, Virtual Threads를 적용했습니다.

**왜 필요한가**: 단일 H2 테스트만으로는 SQL 방언 차이(JSON 타입, 날짜 함수, 트랜잭션 격리)로 인한 프로덕션 DB 회귀를 잡을 수 없습니다. PostgreSQL·MySQL8을 CI에서 동시에 검증해 조기에 감지합니다.

**주요 파일**:
- `appointment-core/src/test/kotlin/.../test/` — `AbstractExposedTest`, `WithDB`, `WithTables`, `Containers`, `TestDB`
- `appointment-api/src/test/kotlin/.../api/test/` — `AbstractApiIntegrationTest`, `Containers`
- `appointment-api/src/test/resources/` — `application-test-postgresql.yml`, `application-test-mysql.yml`
- `appointment-api/build.gradle.kts` — `kotlinx_coroutines_reactor` 추가 (suspend 컨트롤러 지원)
- `.github/workflows/ci.yml` — `test-api` matrix(H2/PG/MySQL), `test-core` RYUK 설정

**검증**:
```bash
./gradlew :appointment-core:test :appointment-event:test :appointment-api:test --parallel
```
