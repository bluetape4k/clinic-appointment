# README 히어로와 WIP 갱신

## 배경

clinic-appointment 앱에는 영문·한국어 README가 있었지만, 공용 workbench 스타일의
시각적 진입점과 최신 WIP 스냅숏이 없었다.

## 결정

생성한 clinic scheduling workbench를
`docs/assets/clinic-appointment-workbench.png`에 저장하고, 두 README
locale에서 참조하며, 현재 할당된 GitHub issue로 `WIP.md`를 생성한다.

## 결과

이제 README는 기능 세부 내용보다 먼저 clinic scheduling 시각 자료와 더 분명한
목적 설명을 보여 준다.

## 검증

- 생성한 asset이 `docs/assets` 아래 PNG로 존재하는지 확인했다.
- 두 README locale이 공용 이미지 경로를 참조하는지 검증했다.
