# 한·영 다이어그램 계획과 변경 내역의 추적성

## 배경

한글 기술 문서를 교정할 때 독자가 직접 보는 다이어그램도 문서 범위에
포함하기로 계획했다. 그러나 첫 변경에서는 Markdown과 HTML 문서 교정에
집중하면서, 계획에 있던 SVG 현지화와 PNG 재생성이 실제 변경 내역에서
빠졌다.

## 원인

- 문서 목록과 이미지 자산 목록을 서로 다른 검증 대상으로 관리하지 않았다.
- README의 이미지 경로가 유효한지만 확인했으며, 경로가 가리키는 이미지의
  언어까지 확인하지 않았다.
- SVG 수정, PNG 재생성, 렌더링 확인을 하나의 완료 조건으로 묶지 않았다.
- 계획의 항목과 최종 diff를 파일 단위로 대조하는 검증이 없었다.

## 결정

독자가 보는 다이어그램은 영문과 한글 자산을 명시적으로 분리한다.

- 영문 문서는 `*-en.svg`와 `*-en.png`를 참조한다.
- 한글 문서는 `*-ko.svg`와 `*-ko.png`를 참조한다.
- 두 SVG는 식별자, 토폴로지, 상대 배치, 연결선 의미, 색상, 기술 식별자를
  동일하게 유지하고 독자용 설명만 번역한다. 글꼴 메트릭에 따른 텍스트
  경계와 캔버스 크기 차이는 허용한다.
- PNG는 대응하는 SVG에서 CairoSVG `-s 2`로 생성한다.
- 완료 전에 SVG XML 검증, 다이어그램 감사, 전체 크기 PNG 확인,
  README 경로 검증을 수행한다.

## 재발 방지 체크

문서 계획에 다이어그램이 포함되면 다음 항목을 계획과 diff에서 각각
대조한다.

1. 영문 SVG
2. 한글 SVG
3. 영문 PNG
4. 한글 PNG
5. 영문 문서 참조
6. 한글 문서 참조
7. 재생성 절차 또는 생성기
8. XML·렌더링·시각 검증 결과

하나라도 빠지면 다이어그램 작업은 완료된 것으로 보지 않는다.
